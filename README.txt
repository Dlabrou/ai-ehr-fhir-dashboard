# 🏥 AI-Powered EHR & Clinical Decision Support System (CDSS)

**AI-Powered Electronic Health Record (EHR) dashboard integrating HL7 FHIR and Machine Learning for clinical decision support.**

Αυτό το έργο αποτελεί ένα ολοκληρωμένο, σύγχρονο ταμπλό Ηλεκτρονικού Φακέλου Υγείας (EHR). Συνδυάζει τη διεθνή διαλειτουργικότητα του προτύπου **HL7 FHIR** με αλγορίθμους **Μηχανικής Μάθησης (Machine Learning)**, λειτουργώντας ως ένα πρακτικό Σύστημα Υποστήριξης Κλινικών Αποφάσεων (CDSS).

Bασικά Χαρακτηριστικά

Διαλειτουργικότητα HL7 FHIR: Ζωντανή διασύνδεση με τον δημόσιο διακομιστή HAPI FHIR για μαζική άντληση, φιλτράρισμα και ανάλυση πραγματικών (συνθετικών) ιατρικών δεδομένων σε μορφή JSON.
Τεχνητή Νοημοσύνη (Predictive Analytics): Ενσωμάτωση αλγορίθμου RandomForestClassifier (εκπαιδευμένου σε συνθετικά βιομετρικά δεδομένα) για την δυναμική αξιολόγηση κινδύνου εμφάνισης διαβήτη τύπου 2.
 Κεντρικό Μητρώο Ασθενών**: Δυναμικό UI με αναζήτηση ασθενών, προβολή δημογραφικών στοιχείων και ανάλυση ζωτικών σημείων σε πραγματικό χρόνο.
Επαγγελματικό User Interface: Σχεδιασμένο με το Streamlit, προσομοιώνει ένα πραγματικό νοσοκομειακό τερματικό ελέγχου.

Τεχνολογίες (Tech Stack)

Γλώσσα Προγραμματισμού: Python 3.x
Διαλειτουργικότητα:** HL7 FHIR (API Integration μέσω requests)
Μηχανική Μάθηση & Δεδομένα: scikit-learn, pandas, numpy
Ανάπτυξη Διεπαφής Χρήστη (Frontend): streamlit

 Εγκατάσταση και Εκτέλεση

Για να δοκιμάσετε την εφαρμογή τοπικά στον υπολογιστή σας, ακολουθήστε τα παρακάτω βήματα στο τερματικό σας:

1. Κλωνοποίηση του αποθετηρίου:
   bash
   git clone [https://github.com/Dlabrou/ai-ehr-fhir-dashboard.git](https://github.com/Dlabrou/ai-ehr-fhir-dashboard.git)
   cd ai-ehr-fhir-dashboard


Εγκατάσταση των απαραίτητων βιβλιοθηκών:
Βεβαιωθείτε ότι έχετε εγκατεστημένη την Python 3. Στη συνέχεια, τρέξτε:

Bash

1  pip install streamlit requests pandas numpy scikit-learn
Εκτέλεση της εφαρμογής:

Bash

2  python -m streamlit run app.py
Η εφαρμογή θα ξεκινήσει τον τοπικό διακομιστή και θα ανοίξει αυτόματα στον προεπιλεγμένο περιηγητή σας (συνήθως στη διεύθυνση http://localhost:8501).
